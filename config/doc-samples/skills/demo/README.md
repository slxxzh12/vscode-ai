# Skills 标准写法

## 文件命名

- 一个技能一个文件：`NN-技能名.md`，例如 `01-接口联调.md`。
- 技能变大时改为目录，目录内保留 `README.md`。

## 文档结构

1. 名称：技能叫什么。
2. 适用场景：什么时候用，什么时候不用。
3. 输入：需要的参数、上下文、文件。
4. 前置条件：环境、权限、依赖。
5. 步骤：可执行的编号步骤。
6. 输出：产出物与格式。
7. 检查清单：完成前必须确认的项。
8. 示例：一个最小可用示例。

## 原则

- 步骤必须可执行，不写「根据情况处理」这类空话。
- 输出格式固定，方便下游消费。
- 技能变更时更新检查清单与示例。
