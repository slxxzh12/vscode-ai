# 示例技能：接口联调

> 示例技能：演示 skills 的标准写法。

## 适用场景

前后端接口开发完成后，需要快速确认请求、响应、错误码是否一致。

## 输入

- 接口文档或 OpenAPI 地址。
- 前端页面地址。
- 测试账号与权限。

## 前置条件

- 后端服务已启动。
- 前端已配置接口代理。
- 测试账号可登录。

## 步骤

1. 打开接口文档，逐项核对路径、方法、参数、响应结构。
2. 用测试账号登录前端，打开浏览器开发者工具网络面板。
3. 在页面触发接口调用，记录请求与响应。
4. 对比文档与真实响应，列出差异。
5. 对错误码逐一验证：参数缺失、无权限、资源不存在。
6. 把差异反馈给对应开发，修复后复验。

## 输出

一份联调记录，包含：

- 接口清单与通过状态。
- 差异项、责任人、修复状态。
- 遗留风险。

## 检查清单

- [ ] 所有接口路径与方法一致。
- [ ] 请求参数与文档一致。
- [ ] 成功响应结构一致。
- [ ] 错误码与提示一致。
- [ ] 无权限场景返回 403。

## 示例

联调 `GET /api/users`：文档返回 `{ list, total }`，实际返回 `{ items, count }`，记录差异并统一为文档结构。
