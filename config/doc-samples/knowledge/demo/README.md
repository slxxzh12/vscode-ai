# 知识库标准写法

## 目录约定

- `demo/` 为初始化示例，可整体删除，不影响流水线。
- 一个主题一个 Markdown 文件，文件名用两位序号开头，例如 `01-术语表.md`。
- 主题变大时拆成子目录，子目录内仍遵守同样的命名规则。

## 文档结构

1. 一句话定义：这个知识解决什么问题。
2. 适用范围：哪些项目、角色、阶段会用到。
3. 核心概念：术语、实体、关系。
4. 规则与约束：必须遵守的边界。
5. 示例：最小可用的正例与反例。
6. 参考资料：来源、版本、更新时间。

## 维护约定

- 事实变化时直接改正文，不保留已过期结论。
- 术语首次出现写成「中文（English）」。
- 每个文件末尾标注 `更新日期` 与 `维护人`。
