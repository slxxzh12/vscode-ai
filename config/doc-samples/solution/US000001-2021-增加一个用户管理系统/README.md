# US000001-2021-增加一个用户管理系统

> 示例方案：演示标准需求从需求到验收的完整流程，可按团队规范替换内容。

## 命名规范

`US<6 位编号>-<年份>-<需求名称>`

示例：`US000001-2021-增加一个用户管理系统`

## 标准流程

| 阶段 | 文件 | 产出 | 完成标准 |
| --- | --- | --- | --- |
| 1. 需求分析 | `01-需求分析.md` | 背景、目标、范围、验收标准 | 需求方可确认 |
| 2. 方案设计 | `02-方案设计.md` | 架构、数据模型、接口、权限 | 技术评审通过 |
| 3. 任务拆分 | `03-任务拆分.md` | 可执行任务与依赖 | 任务可排期 |
| 4. 开发实现 | 代码仓 | 功能与测试 | 自测通过 |
| 5. 联调验收 | `04-验收清单.md` | 验收记录 | 验收项全部通过 |
| 6. 复盘沉淀 | 经验库 | 经验文档 | 经验入库 |

## 目录说明

- 一个需求一个文件夹，文件夹名即需求编号与名称。
- 阶段文件按两位序号命名，新增阶段继续向后编号。
- 需求变更时更新对应文件，并在文末记录变更历史。
