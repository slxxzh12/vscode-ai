# 05-构建发布

> 供代码生成流水线自动执行：`test` / `build` 必填，`package` 可选。缺少 `build` 会导致该方案开发失败。

## 测试

```bash
npm test
```

## 构建

```bash
npm run build
```

## 打包

```bash
npm run package
```

## 说明

- 命令在**代码仓**根目录执行，不是文档仓。
- 也可改用方案根目录的 `pipeline.json`（`{"test":"...","build":"...","package":"..."}`）或 `01-需求分析.md` 的 frontmatter 提供；三者按此优先级取第一个非空值。
