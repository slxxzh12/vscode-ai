# 01 需求分析

## 背景

现有系统没有统一的用户管理能力，账号散落在各业务模块，权限无法统一控制。

## 目标

建设一个统一的用户管理系统，支持账号、组织、角色、权限的集中管理。

## 范围

### 包含

- 用户新增、修改、禁用、删除（软删除）。
- 按组织查看用户。
- 角色与权限分配。
- 登录、登出、重置密码。

### 不包含

- 第三方单点登录（后续需求）。
- 跨租户数据迁移。

## 角色

| 角色 | 权限 |
| --- | --- |
| 超级管理员 | 全部权限，可转移管理员 |
| 管理员 | 管理本租户用户与角色 |
| 普通用户 | 查看与修改本人资料 |

## 功能需求

1. 用户列表支持分页、按姓名/手机号搜索。
2. 新增用户时校验用户名唯一。
3. 禁用用户后立即失去登录能力。
4. 删除用户为软删除，保留审计记录。

## 非功能需求

- 列表接口 P95 响应时间小于 300ms。
- 敏感操作全部记录审计日志。
- 权限校验必须在服务端完成。

## 验收标准

- 上述功能需求全部可用。
- 越权访问返回 403。
- 审计日志可查询到操作人、时间、对象、结果。
