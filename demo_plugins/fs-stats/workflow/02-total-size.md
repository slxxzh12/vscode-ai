# 第二步：汇总所有文件的总大小

目标目录与忽略规则同第一步。

要求：

- 递归遍历目标目录，累加**所有文件**的字节数；
- 换算成 KB / MB，保留合适的小数位；
- 列出占用最大的前 5 个文件（相对路径 + 大小）。

最后把第一步与第二步的结果写入 `output/report.md`，格式示例：

```
# 目录文件统计

目标目录：<目录>

## 第一步：.js 文件数量
- 共 N 个 .js 文件
- 清单：
  - path/to/a.js
  - ...

## 第二步：文件总大小
- 所有文件总大小：X 字节（约 Y MB）
- 最大的 5 个文件：
  1. path/to/a.js — ...
  2. ...
```
