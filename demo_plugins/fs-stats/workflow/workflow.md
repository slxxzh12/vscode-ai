# 目录文件统计（多文件工作流）

本工作流由多个 Markdown 子文件组成，请**严格按顺序**执行，不要跳步：

1. 读取并执行 `01-count-js.md` —— 统计 `.js` 文件数量。
2. 读取并执行 `02-total-size.md` —— 汇总所有文件的总大小。

开始前先读取当前目录下的 `input.json`，取 `dir` 字段作为目标目录：
- 留空或 `.` → 使用当前工作目录；
- 否则使用该路径。

两步都完成后，按 `02-total-size.md` 末尾的格式把结果汇总写入 `output/report.md`。
只读取目标目录，不要修改 `output/` 之外的任何文件。
