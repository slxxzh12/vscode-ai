# Markdown 引用示例

这是一个 Markdown 文件，演示如何引用其他文件。

## 引用 CSV 文件

- [示例数据表](./data.csv)
- 行内链接：`./data.csv`

## 引用另一个 Markdown 文件

- [另一个文档](./another.md)

## 说明

- 使用相对路径 `./文件名` 可保证仓库迁移后链接依然有效。
- CSV 一般作为下载/原文附件打开，不要用 `![...]()` 图片语法嵌入。
