# 04 验收清单

## 功能验收

- [ ] 用户列表分页正确，无重复、无遗漏。
- [ ] 按姓名、手机号搜索返回正确结果。
- [ ] 新增用户用户名重复时返回 409。
- [ ] 禁用用户后无法登录。
- [ ] 软删除用户后列表不可见，审计可查。
- [ ] 角色与权限分配后立即生效。

## 权限验收

- [ ] 低权限账号调用删除接口返回 403。
- [ ] 前端隐藏按钮与后端权限一致。
- [ ] 超级管理员操作正常。

## 数据与审计

- [ ] 敏感操作写入审计日志。
- [ ] 审计日志包含操作人、时间、对象、结果。
- [ ] 列表接口 P95 小于 300ms。
