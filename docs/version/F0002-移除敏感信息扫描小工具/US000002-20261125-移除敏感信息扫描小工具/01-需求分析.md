# 01 需求分析

## 背景

应用里存在两个都叫「敏感信息扫描」的功能：

- 小工具：市场/欢迎页的小工具磁贴（`security`），独立的扫描目录 + 结果列表。
- 代码统计页签：`代码统计 → 敏感信息扫描`，支持关键词/类别配置、批量目录、导出与 AI 复核。

用户确认只保留代码统计页签，删除独立小工具，避免重复入口与重复维护。

## 目标

- 彻底移除「小工具 → 敏感信息扫描」的入口、组件、接口、扫描实现、测试、词条与说明文档。
- 不影响「代码统计 → 敏感信息扫描」页签。
- 不涉及数据库迁移，不改变其他小工具。

## 范围

### 包含

- 小工具目录项（`ToolId='security'`）与磁贴。
- 前端组件 `web/src/tools/security/SecurityTool.vue`。
- 后端接口 `POST /api/security/scan` 与 `server/security/scan.js`。
- 相关测试与 i18n 词条（`tools.security`、`tools.desc.security`、`security.*`）。
- 说明文档 `docs/knowledge/security-scan.md`。

### 不包含

- `代码统计 → 敏感信息扫描` 页签：`SecretScan.vue`、`secretScan.ts`、`/api/code/secret-scan`、`server/secret-scan.js`、`codestat.scan.*`。
- 提交前的「敏感信息扫描」检查流程（`docs/learn/git仓库提交检查和提交事项.md`）。
- 其他小工具与通用目录选择逻辑。

## 验收标准

- 市场/欢迎页不再出现「敏感信息扫描」小工具磁贴。
- 活动栏不再有该工具的页签与内容。
- `POST /api/security/scan` 返回 404。
- 代码统计中的「敏感信息扫描」页签功能保持可用。
- 类型检查、i18n 检查、前后端测试全部通过。
