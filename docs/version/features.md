## 规则

- 特性编号：`F` + 4 位数字，唯一且不复用。
- 方案目录：`docs/version/` 下的相对路径；同一特性有多个方案时用英文逗号分隔（如 `F0001-用户管理/US000001-...,F0001-用户管理/US000002-...`）。
- 不要删除已被方案引用的行；下线特性时在「说明」里标注。
- 应用内保存方案文档时从本清单选择特性编号，保存到对应方案目录。
