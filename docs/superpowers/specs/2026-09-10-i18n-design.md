# 设计文档：全应用国际化（i18n，至少中/英）

日期：2026-09-10
分支：master
状态：待评审

## 1. 概述

把当前代码中**用户可见的中文文案**全部替换为国际化词条，至少支持 **简体中文（zh-CN）** 与 **英文（en）**。

范围覆盖前端（`web/src/**`）与服务端（`server/**`）中会呈现给用户、或由服务端下发到界面的文案。实现采用**共享自研轻量 i18n**（`shared/i18n/`），前端与服务端复用同一套词条与运行时。

### 已与用户确认的约束

- 范围：**前端 + 服务端用户可见文案**（含 API 错误 message、协作系统消息）。
- 实现：**共享自研轻量 i18n**（单一词条源，web/server 复用，无新依赖）。
- 服务端语言：**全局设置**，存 `config/server.json` 的 `language` 字段。
- 切换与持久化：**一个开关**（顶栏）；切换即时生效并写 `localStorage`，同时同步服务端；默认按浏览器语言。

## 2. 范围与排除

**做：**
- `web/src/**` 中所有界面文案：按钮、标题、菜单/tab、占位符、`title`/`aria-*`、toast、前端校验与错误提示。
- 非组件 TS 模块中的用户可见字符串：`gitStat.ts`、`curl.ts`、`collaboration/chat-parser.ts`、`useMessageHistory.ts`、`nodeKey.ts`、`useTerminal.ts`、`markdown.ts` 等。
- 服务端对界面下发的文案：`http-mount.js` / `http-api.js` 的 `message`/`error`、`collaboration/engine.js` 的协作系统消息。
- `config/server.json` 增加 `language`，并新增读写端点。

**明确排除（不本地化）：**
- 代码注释。
- `console` / `logger` 日志（`createLogger` 输出）。
- 测试文件（`*.test.*`）。
- 配置/用户内容：`config/workflow.xml` 提示语、`projects.json` 名称、`workflows.json`、用户输入的群名/用户名/文件名等。
- 第三方库文案、浏览器原生控件。

## 3. 架构与文件

```
shared/i18n/
  index.js         translate(locale, key, params)、normalizeLocale、LOCALES、DEFAULT_LOCALE
  zh-CN.js         词条表
  en.js            词条表
shared/package.json  exports 增 "./i18n"
```

```
web/src/i18n.ts    Vue 响应式封装：locale ref、t()、setLocale()、useI18n()
web/src/main.ts    注册全局 $t
web/src/App.vue    顶栏「中 / EN」开关
```

```
server/i18n.js     模块级 currentLocale + t()/setLocale()（读 shared 词条）
server/settings.js readSettings/writeSettings 增加 language
server/index.js    GET /api/settings 返回 language；POST /api/settings/language
scripts/check-i18n.js  守卫脚本（npm run check:i18n）
```

模块边界：
- `shared/i18n/index.js`：纯函数，无任何环境依赖，可被 web 与 server 同时 import。
- `web/src/i18n.ts`：只负责「当前语言状态 + 响应式 + 持久化 + 同步服务端」，翻译本身委托 shared。
- `server/i18n.js`：只负责「服务端全局语言状态」，翻译本身委托 shared。

## 4. 词条格式与运行时 API

- 扁平点分键：`nav.explorer`、`collab.group.create`、`file.save.failed`。按功能域前缀分组，便于检索与漏译检测。
- 词条值用 `{name}` 占位符：`"已向群发送文件：{name}（{kb} KB）"`。
- 复数：不引入 ICU；复数场景用两条键（`..._one` / `..._other`），调用处按 `count` 选择。中文无复数，两条取同值或直接用单条。
- 缺失键回退顺序：`当前语言 → en → 返回 key 本身`（开发期直接暴露漏译 key）。
- `normalizeLocale(x)`：`zh*` → `zh-CN`；`en*` → `en`；无法识别 → `DEFAULT_LOCALE`（`zh-CN`）。

`shared/i18n/index.js` 导出：

```js
export const LOCALES = ['zh-CN', 'en'];
export const DEFAULT_LOCALE = 'zh-CN';
export function normalizeLocale(x) { /* ... */ }
export function translate(locale, key, params) { /* 插值 + 回退 */ }
```

## 5. Web 集成

`web/src/i18n.ts`：

- `locale: Ref<string>`，初值：`localStorage['devflow-lang']` → `navigator.language` → `DEFAULT_LOCALE`（用 `normalizeLocale`）。
- `t(key, params)`：读取 `locale.value` 后调用 shared `translate`；因读取响应式 ref，模板中随语言切换自动重渲染。
- `setLocale(x)`：`normalizeLocale` 后更新 ref、写 `localStorage['devflow-lang']`、`POST /api/settings/language { language }`（失败静默，不影响本地切换）。
- `useI18n()` 返回 `{ locale, t, setLocale }`。
- `main.ts`：`app.config.globalProperties.$t = t`，模板统一用 `$t('key', {...})`；TS 模块用相对路径 `import { t } from '../i18n'`。
- `App.vue` 顶栏主题按钮旁加「中 / EN」切换按钮，点击 `setLocale`。
- 日期/时间按 locale 用 `toLocaleString(locale.value)` 替换现有硬编码格式。

## 6. 服务端集成

- `server/settings.js`：`readSettings` 返回 `{ port, language }`（缺省 `language = DEFAULT_LOCALE`）；`writeSettings` 合并写入并校验取值必须属于 `LOCALES`。
- `server/i18n.js`：

```js
import { translate, normalizeLocale, DEFAULT_LOCALE } from '@devflow/shared/i18n';
let currentLocale = DEFAULT_LOCALE;
export function setLocale(x) { currentLocale = normalizeLocale(x); }
export function getLocale() { return currentLocale; }
export function t(key, params) { return translate(currentLocale, key, params); }
```

- `server/index.js`：
  - 启动时 `setLocale(readSettings(settingsFile).language)`。
  - `GET /api/settings` 返回体加入 `language`。
  - 新增 `POST /api/settings/language { language }`：校验属于 `LOCALES`，`writeSettings` 写盘 + `setLocale` 更新内存，返回 `{ language }`；非法值 400。
- 迁移点（仅用户可见）：
  - `collaboration/http-mount.js`：面向界面的 `message`/`error` → `t(key, params)`。
  - `collaboration/engine.js`：系统消息（`已向群分发…`、`已向群发送文件…`、`拒绝了 @… 的远程执行`、`远程执行未送达…`）→ `t(key, params)`。
  - `http-api.js` 等面向界面的 `message` → `t(key, params)`。
- **默认服务端语言 = `zh-CN`**，与现状输出一致，现有断言中文的测试保持通过。

## 7. 覆盖保障与迁移

- 逐文件迁移：字面量 → key，同时在 `zh-CN.js`/`en.js` 补齐词条。
- 守卫脚本 `scripts/check-i18n.js`（`npm run check:i18n`）：
  - 扫描 `web/src/**`：提取 `.vue` 的 `<template>` 段；对 `.ts/.js` 剥离 `//` 与 `/* */` 注释后扫描字符串字面量。
  - 扫描 `server/**`：剥离注释后扫描字符串字面量（日志行可显式白名单）。
  - 命中中文即打印 `文件:行:内容` 并以非零码退出。
  - 迁移完成后应零命中；作为最终验收项之一。
- 排除目录：`shared/i18n/**`、`*.test.*`、`node_modules`、`web/dist`。

## 8. 测试

- shared 单测（`server/test/i18n.test.js`）：`translate` 插值、缺失回退（当前→en→key）、`normalizeLocale`。
- web vitest（`web/src/i18n.test.ts`）：默认语言探测顺序、`setLocale` 持久化与响应式重渲染、`t` 回退。
- server（`server/test/settings.test.js` 扩展 / `scheduler` 无关）：`language` 读写、`POST /api/settings/language` 合法/非法、engine 系统消息按配置语言输出（默认 zh-CN 与现状一致）。
- 守卫：`npm run check:i18n` 在用户可见范围零命中。
- 既有 `npm.cmd test` + `npm.cmd run typecheck` 全绿。

## 9. 实施拆分（一个 spec，分里程碑的 plan）

1. **核心**：`shared/i18n/*` + `shared/package.json` exports + `web/src/i18n.ts` + `main.ts` + `App.vue` 开关 + `server/settings.js`/`server/i18n.js`/`server/index.js` 端点 + `scripts/check-i18n.js`。
2. **Web 全量迁移**（按区域分批，逐批 `check:i18n` 收敛）：
   - 外壳与导航（`App.vue`、`CollaborationView.vue`、主题/设置）。
   - 资源管理与历史（`FileTree`、`HistoryList`、`FilePreview`、`useMessageHistory`、`nodeKey`、`markdown`）。
   - 终端与统计（`TerminalView`、`WorkflowPanel`、`GitStat`、`gitStat.ts`、`curl.ts`、`useTerminal`）。
   - 协作（`ContactsView`、`GroupChatView`、`JoinInviteCard`、`SkillDistributor`、`TasksView`、`chat-parser`、`useCollab`）。
   - 调度（`SchedulerView`、`format.ts`、`useScheduler`）。
3. **服务端用户可见文案迁移**：`http-mount.js`、`engine.js`、`http-api.js`；补 `check:i18n` 白名单规则。

> 若单份 plan 过长，可在里程碑 2 内部再拆为独立 plan；spec 保持单一。

## 10. 决策记录

- 不引入 vue-i18n：服务端无法复用；自研轻量运行时约 30 行即可覆盖插值+回退，符合仓库「少依赖」风格。
- 服务端不做按请求翻译：用户选择全局语言，实现简单且满足本地单机/团队场景；协作系统消息按服务端当前语言固化文本。
- 默认 zh-CN：零行为回归，保护现有测试。
- 注释/日志/配置内容不迁移：不属于「用户提示」，且翻译无意义。
