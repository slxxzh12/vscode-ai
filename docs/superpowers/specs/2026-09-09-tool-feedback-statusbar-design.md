# FilePreview 工具反馈 → 底部常驻状态栏 设计

日期：2026-09-09

## 目标

文件预览（FilePreview）顶栏工具按钮（⇥ 格式化 / ⇣ 压成一行 / ⇅ 排序 / ▶ 运行）以及自动保存状态，目前以「顶栏内嵌文字、闪烁几秒即消失」或 `alert()` 弹窗的形式反馈，位置忽隐忽现且不稳定。

本次改造：将工具反馈与保存状态统一收敛到**文件预览区底部的一条常驻单行状态栏**，替代顶栏闪字与弹窗。要求：

- 反馈信息保留到下一条消息出现（不自动消失）。
- 保存状态永远位于状态栏最前（最左）。
- 状态栏**常驻固定占用**，不随内容出现/消失而改变布局 → 预览/代码区可视高度恒定，位置永不变动。
- 不影响「预览/代码」切换分栏的布局。

## 方案

### 布局结构（FilePreview 最底部）

所有文件类型（文本/图片/PDF）统一渲染常驻状态栏，位于 flex 列的最后：

```
[编辑器 / 预览区      flex:1]   ← 高度恒定，不再受反馈文字影响
[Base64 面板(开时)]  [详情面板(开时)]  ← 原有面板，叠在状态栏上方
[──────── 底部状态栏 flex:none 单行 ~24px ────────]
```

状态栏永久占位（`flex: none`），因此其存在与否不改变上方区域尺寸；开关 Base64/详情面板的既有行为（会挤压编辑器）保持不变，本次不改动。

### 状态栏内容（从左到右）

1. **保存状态段（最前）**：反映 `saveState`。
   - `saving` → `保存中…`
   - `saved` → `✓ 已保存 12:03:45`
   - `error` → `⚠ 保存失败：xxx`（可点击重试）
   - `idle` → 不占位
2. **工具反馈段（保存状态之后）**：记录最近一次工具操作结果，保留到下一条消息出现才被覆盖；切文件时清空。
   - 颜色区分成功 / 错误。
   - 文案清单见下。

### 工具反馈文案（成功类新增，错误类沿用现有 message）

| 工具 | 成功 | 失败 |
|---|---|---|
| ⇥ 格式化 | `✓ 已格式化` / `格式已是最佳` | `⚠ 格式化失败：<msg>` |
| ⇣ 压成一行 | `✓ 已压缩为一行` | `⚠ 压缩失败：<msg>`（替代现有 `alert()`） |
| ⇅ 排序 | `✓ 已按<排序方式>排列` | （无失败分支） |
| ▶ 运行 | `✓ 已在系统中执行` | `⚠ 执行失败：<msg>` |

排序模式→文案映射：`asc`→升序、`desc`→降序、`asc-ci`→升序(不分大小写)、`desc-ci`→降序(不分大小写)、`num-asc`→数字升序、`num-desc`→数字降序。

### 移除的旧反馈路径

- 顶栏 `.right` 内 `fmtMsg` 文字、`runMsg` 文字、保存状态 span（`保存中…`/`✓ … 已保存`/`⚠ 保存失败`）全部删除，顶栏只留按钮。
- 删除 `flashFmt()` 的 2.6s 定时器、`runFile()` 的 3.2s 自动清除定时器及其 `runTimer`/`fmtTimer`。
- `minifyOneLine()` 失败不再 `alert()`，改写入状态栏。

## 数据流

- 新增一个共享状态：`toolMsg`（`{ text: string; ok: boolean }` 或独立 `okMsg`/`errMsg` 字段），初始 `null`。
- 保存状态段直接读现有 `saveState`/`saveMsg`（`saveMsg` 目前仅存时间戳，改为完整显示用，仍复用）。
- 各工具函数成功/失败统一调用 `setToolMsg(text, ok)` 写入 `toolMsg`。
- `load()`（切文件）时清空 `toolMsg`；`saveState` 由现有写逻辑自然复位。
- `onRetrySave()` 点击错误段时重试，行为不变。

## 空态

无任何保存/工具反馈时，状态栏整条留白（仅保留固定高度占位）。

## 错误处理

- 工具错误信息原文透传（`e?.message || e`）。
- 状态栏文字过长：单行省略（`ellipsis`），`title` 提供完整文案。

## 测试

- Web 单元/组件行为：确认 `fmtMsg`/`runMsg`/`alert` 相关旧定时器逻辑删除后无遗留引用（typecheck + vitest 全绿）。
- 手动验证路径：打开文本文件 → 逐一点击 格式化/压成一行/排序/运行 → 观察反馈进状态栏且保留；切换文件 → 反馈清空；编辑触发保存 → `保存中…`→`✓ 已保存` 出现在状态栏最前；触发保存失败（改只读文件等）→ `⚠ 保存失败` 可点击重试；打开 Base64/详情面板确认布局稳定不跳动。

## 范围外（YAGNI）

- 不改 WorkflowPanel / 协作任务页的任何提示。
- 不做多行日志/历史列表。
- 不改 Base64/详情面板开关时挤压编辑器的既有行为。
