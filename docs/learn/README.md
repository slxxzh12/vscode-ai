# 工作流

本目录是**工作流 / 流程规范仓库**，存放团队如何协作、如何交付的流程说明。

## 放什么

- 研发、评审、发布、排障等流程说明。
- 每个阶段的责任人、输入、动作、产出与完成标准。
- 流程异常与回退处理方式。

## 不放什么

- 单个需求的方案 → 放 `docs/version/`（方案仓）。
- 稳定知识或术语 → 放 `docs/knowledge/`（知识库）。
- 具体某次事故的复盘 → 放 `docs/memory/`（经验库）。

## 归档与命名

- 一个流程一个文件：`流程名.md`；多版本用 `流程名-v2.md` 区分并保留旧版本。
- 每个阶段必须有明确产出，完成标准必须可验证。
- `demo/` 为初始化示例，可整体删除。

写法细则见本目录 `demo/README.md`。
