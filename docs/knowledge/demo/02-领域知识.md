# 领域知识：用户管理

> 示例文档：演示领域知识的组织方式。

## 一句话定义

用户管理负责账号生命周期、身份认证、组织归属与权限授予。

## 适用范围

- 新增、修改、禁用、删除用户。
- 登录、登出、找回密码。
- 角色与权限分配。

## 核心概念

- 账号：登录凭证，包含用户名、密码摘要、状态。
- 资料：昵称、邮箱、手机号等展示信息。
- 组织：部门树，决定数据可见范围。
- 审计：所有敏感操作留痕，可追溯。

## 规则与约束

- 用户名全局唯一，手机号与邮箱可重复但需验证。
- 禁用用户不能登录，但历史数据保留。
- 超级管理员不可删除，只能转移。

## 示例

新增用户流程：创建账号 → 绑定组织 → 分配角色 → 发送激活邮件 → 首次登录强制改密。
