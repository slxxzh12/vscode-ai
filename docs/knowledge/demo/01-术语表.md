# 术语表

> 示例文档：演示知识库的标准写法，可按团队实际情况替换。

## 一句话定义

统一用户管理系统中的核心术语，避免需求、设计、开发、测试各阶段叫法不一致。

## 适用范围

- 用户管理、权限管理、组织架构相关需求。
- 需求评审、方案设计、接口联调、验收测试。

## 核心概念

| 术语 | English | 说明 |
| --- | --- | --- |
| 用户 | User | 系统中的登录主体，拥有唯一账号。 |
| 角色 | Role | 一组权限的集合，用户通过角色获得权限。 |
| 权限 | Permission | 对某个资源执行某个动作的许可。 |
| 租户 | Tenant | 数据隔离单元，一个租户内数据互不可见。 |
| 会话 | Session | 用户登录后到退出前的有效上下文。 |

## 规则与约束

- 用户必须归属于唯一租户。
- 角色可以叠加，权限取并集。
- 删除用户采用软删除，保留审计记录。

## 示例

「给运营角色增加导出用户列表权限」：找到 `operator` 角色，挂载 `user:export` 权限，用户重新登录后生效。
