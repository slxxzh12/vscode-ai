# 安全扫描小工具

## 入口

「市场 → 小工具 → 安全扫描」，或活动栏工具页签。

## 扫描范围

- 敏感信息：私钥、GitHub / GitLab / Slack / AWS / Gitee token、带凭据 URL、疑似密钥赋值。
- 危险文件：`.env`、`*.pem`、`*.key`、`*.p12`、`*.pfx`、`*.db`、`*.sqlite`、`id_rsa` 等。
- `env/` 目录下的文件。
- 自动跳过 `.git`、`node_modules`、`dist`、`dist-portable`、`logs` 等目录。

## 使用

1. 选择一个或多个目录。
2. 点「开始扫描」。
3. 按高危 / 中危 / 低危查看文件与行号。

扫描结果只在本机展示，不上传；发现真实凭据后应尽快轮换。
