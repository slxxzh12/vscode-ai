# 左文右图表格样例

用一张占满可用宽度的表格，左侧放文字说明，右侧放图片。

<!-- df-table width=100% -->

| 说明 | 示意图 |
| --- | --- |
| **步骤一：准备环境**<br><br>先安装 Node，再准备项目目录。图片放在同目录或子目录下，用相对路径引用即可。 | ![步骤一](sample-image.svg){width=240} |
| **步骤二：编写配置**<br><br>在 Markdown 中使用相对路径引用图片；需要控制大小时在图片后加 `{width=...}`。 | ![步骤二](sample-image.svg){width=180} |
| **步骤三：预览效果**<br><br>左侧文字会自动换行，右侧图片可以用 `{width=100%}` 填满当前单元格；表格整体占满可用宽度。 | ![步骤三](sample-image.svg){width=100%} |

---

说明：

- `<!-- df-table width=100% -->` 让表格占满可用宽度。
- 左列写文字，右列写图片即可。
- 图片尺寸可用 `{width=240}`、`{width=50%}`、`{width=100%}` 控制。
- 即使表格占满宽度，单元格内的图片仍按自身宽度显示。
