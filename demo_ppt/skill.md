# Markdown 制作 PPT 的标题规范

# 1 适用范围

适用于本目录（`demo_ppt/`）中所有用于生成 PPT 的 Markdown 文件。

# 2 标题编号规范

## 2.1 数字编号

正文标题必须使用阿拉伯数字编号，采用 `1`、`1.1`、`1.2` 的层级格式；文档标题（封面）可不编号。

## 2.2 层级规则

文档标题用一级标题（`#`）且不编号，作为封面页；正文一级标题（`#`）使用 `1`、`2`、`3`……，二级标题（`##`）使用 `1.1`、`1.2`、`2.1`……，以此类推。PPT 按一级标题（`#`）切分页面。

## 2.3 书写格式

标题编号与标题文字之间用空格分隔；除文档标题、鸣谢等封面/附录外，正文不允许出现无编号的章节标题。

# 3 一页一观点

## 3.1 一个一级标题表达一个观点

每个一级标题对应一页（或一个章节页），只表达一个核心观点；标题尽量写成结论，而不是宽泛的分类名。

## 3.2 控制在一页内展示

正文用要点、表格或图表支撑该观点，避免大段文字堆叠，确保内容能在界面/投影的一页内完整展示，不跨页。

## 3.3 与 void PPT 生成对接

后续由 void ppt 生成功能按一级标题切分页面，因此一级标题的粒度应保持一致，便于自动排版与生成。

## 3.4 页面结构

每页统一按「结论式标题 + 支撑材料」组织：

- 标题即结论，一页只讲一个观点；
- 支撑材料优先用一张表、一组要点或一张图，不堆叠大段文字；
- 封面单独一页，正文每页对应一个一级标题，结尾收束一页；
- 内容必须在一页内完整展示，跨页说明该页观点过多，应拆分。

## 3.5 页面密度

- 一页不宜只有一个短句或一张小表，避免页面太空。
- 可将 2–3 个相关章节合并到一个一级标题下，用 1.1、1.2 等二级标题组织，让每页信息量饱满且仍围绕一个核心观点。

# 4 示例

```markdown
# 报告标题

# 1 评测是 Agent 的核心

## 1.1 为什么评测是核心

## 1.2 Agent 评测与模型评测的区别

# 2 三个核心评测指标

## 2.1 Outcome（结果）

## 2.2 Trace（过程）
```
